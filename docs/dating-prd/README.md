# Dating App PRD

This folder contains the product requirements documentation for the dating app.

It is derived from `../dating-product-foundation.md` and should be used as the product reference before implementation.

## Files

- `overview.md` — product goals, scope, personas, and success criteria
- `experience.md` — onboarding, profile, discovery, match, chat, and moderation flows
- `matching.md` — product behavior for eligibility, ranking, cold start, and quality logic
- `roadmap.md` — scoped delivery split between v1, v1.1, and later ideas

## Reading Order

1. `overview.md`
2. `experience.md`
3. `matching.md`
4. `roadmap.md`

## Relationship To Technical Docs

This folder describes what the product must do.

The implementation details, data model, API contracts, and system design live in `../dating-technical/`.

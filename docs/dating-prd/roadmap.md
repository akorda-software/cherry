# PRD Roadmap

## v1

The first release should include:

- Apple and Google sign-in
- Mandatory onboarding with complete profile requirements
- Bio, photos, intent, tags, and distance preference
- Location-based discovery using current location
- Mutual-like match creation
- Text-only chat
- Match expiry after 7 days without messages
- Unlimited likes with anti-abuse protections
- New-user boost
- Basic safety actions
- Basic admin moderation tools
- Basic product analytics

## v1.1

The next iteration should focus on refinement, not expansion for its own sake.

Planned candidates:

- Phone authentication
- Better tag catalog tuning
- Ranking weight refinement from observed metrics
- Better low-supply fallback tuning
- Improved admin tooling
- Better moderation workflows
- More detailed analytics
- Optional manual search area in addition to current location

## Later Ideas

These are intentionally outside near-term scope:

- Monetization features
- Premium plans
- Boosts and super likes
- Media messaging
- Advanced identity verification
- ML-based ranking
- Compatibility quizzes or deeper profile prompts

## Delivery Guidance

The product should be shipped in layers:

1. Solid core matching and onboarding
2. Safety and admin operability
3. Analytics and tuning
4. Post-launch refinement

The roadmap should favor quality improvements over feature expansion.

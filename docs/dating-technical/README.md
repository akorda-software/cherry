# Dating App Technical Plan

This folder contains the technical implementation documentation for the dating app.

It translates the product decisions from `../dating-product-foundation.md` and `../dating-prd/` into architecture, data model, backend responsibilities, and delivery steps.

## Files

- `architecture.md` — system boundaries, app responsibilities, and core technical decisions
- `data-model.md` — domain entities, PostgreSQL model, and geospatial storage strategy
- `backend.md` — Phoenix contexts, APIs, jobs, moderation, and ranking responsibilities
- `mobile.md` — Expo app flows, state boundaries, permissions, and feature modules
- `delivery-plan.md` — implementation phases, sequencing, and technical milestones

## Reading Order

1. `architecture.md`
2. `data-model.md`
3. `backend.md`
4. `mobile.md`
5. `delivery-plan.md`

## Relationship To Product Docs

This folder explains how the product should be built.

The product intent, requirements, and scope live in `../dating-prd/`.
